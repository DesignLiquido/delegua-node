# Avaliadores Sintáticos de `delegua-node`

Todos os avaliadores sintáticos implementados aqui possuem capacidades de acesso ao sistema operacional e recursos de rede do computador, que é o que Node.js nos permite fazer. Isso confere algumas capacidades, como importação de outros fontes e importação de bibliotecas, e com elas, funcionalidades a mais, como verificação de tipos.
