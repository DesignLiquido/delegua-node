# Cobertura de código e reportadores

Este diretório contém a implementação da cobertura de código para a suíte de testes de Delégua, bem como reportadores que geram relatórios de cobertura em diferentes formatos. A cobertura de código é uma métrica que indica quais partes do código foram executadas durante os testes, ajudando a identificar áreas que podem precisar de mais testes.
